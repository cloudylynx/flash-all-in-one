# Flash All In One 高级功能用户协议

**版本 1.0 · 生效日期 2026-10-31**

---

## 一、适用范围

本协议适用于本软件的「高级功能」区域，包括但不限于：

- Bootloader 解锁（高通 / 联发科 / 华为麒麟 / 摩托罗拉）
- MTK seccfg 分区改写
- MTK LK 镜像补丁
- RPMB magic 擦除
- Val Protocol 解锁
- EDL 深度刷机（9008）
- 分区读写与擦除
- 任何涉及底层分区、Bootloader、BROM / EDL 模式的操作

**普通功能**（ADB 设备管理、应用管理、文件传输、屏幕投屏、日志查看等）不在本协议范围内。

## 二、风险告知

**请你务必理解以下事实：**

1. **可能变砖。** 上述操作涉及设备最底层的引导链。任何一个参数错误、断电、线材松动、版本不匹配，都可能导致设备无法开机、无法进入 Recovery、无法进入 Fastboot，甚至需要拆机短接或更换主板才能救回。

2. **数据会丢失。** Bootloader 解锁在绝大多数设备上会强制清空用户数据，包括照片、聊天记录、文档、应用数据。**这个操作不可逆。**

3. **保修会失效。** 解锁 Bootloader 通常会被厂商记录（如三星 Knox 熔断、小米云端标记），导致失去官方保修资格，部分设备还会永久失去 Samsung Pay、银行类应用、DRM 高清播放等功能。

4. **可能违反服务条款。** 部分厂商的保修条款、用户协议明确禁止解锁 Bootloader。由此产生的纠纷由你自行承担。

5. **工具本身可能有缺陷。** 本软件是开源项目，代码公开可审查，但**不保证没有 bug**。依赖的第三方工具（mtkclient、lkpatcher、val-protocol、fh_loader、QSaharaServer 等）由各自作者维护，本软件不对其正确性负责。

6. **无法保证适配你的设备。** 解锁方法与设备型号、SoC、系统版本、安全补丁级别高度相关。**同一型号不同批次都可能不通用。**

## 四、使用前提

使用高级功能前，你应当确认：

1. 你**拥有该设备的所有权**，或已获得所有者明确授权
2. 你**已完整备份**所有重要数据到设备之外的位置
3. 你**了解该设备的型号、SoC、系统版本**，并确认该解锁方法适用于它
4. 你**已准备好救砖方案**（原厂固件、9008 线、短接工具、可用的电脑等）
5. 你**理解操作步骤**，不是在盲目点击按钮
